# Electron + React + Vite

This project is generated by `create-frontron`.

## Commands

```bash
npm run dev       # browser-only Vite development
npm run app       # Vite development inside Electron
npm run typecheck
npm run lint         # check JavaScript and TypeScript
npm run format       # apply formatting
npm run format:check # verify formatting
npm run build     # build and package the desktop app
```

## Window behavior

The app uses the operating system's native title bar. The generated BrowserWindow keeps Node integration disabled, sandboxing enabled, and context isolation enabled.

External HTTP and HTTPS links open in the system browser. Other cross-origin navigation and new Electron windows are blocked.

## Native bridge

Electron mode exposes a constrained API on `window.electron`:

```ts
await window.electron?.getAppInfo()
await window.electron?.openTextFile()
await window.electron?.saveTextFile({
  defaultPath: 'note.txt',
  content: 'Hello\n',
})
await window.electron?.readClipboardText()
await window.electron?.writeClipboardText('Copied text')
await window.electron?.showNotification({ title: 'Done' })
```

Open and save operations use native dialogs. Text reads and writes are limited to 16 MiB, and the renderer is not given a general filesystem or Node.js API.

Extend these files when the application needs additional native capabilities:

```text
src/electron/preload.ts
src/electron/ipc.ts
src/types/electron.d.ts
```

The renderer ships every [shadcn/ui](https://ui.shadcn.com) component (Base UI primitives, `base-nova` style, Tailwind CSS 4) in `src/components/ui`. Import them with the `@/components/ui/*` alias. Add or update components with `npx shadcn@latest add <name>`. `shadcn/tailwind.css` is ejected into `src/index.css`, so the shadcn CLI is not an app dependency; shadcn's own updates to that file are not applied automatically.

Light and dark themes follow the operating system color scheme through the `.dark` class set in `src/main.tsx`.

The static renderer server supports SPA fallback, byte ranges, common web media types, and confinement against traversal or escaping symlinks.
